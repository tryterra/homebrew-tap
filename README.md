# Terra CLI Homebrew tap

Set up and debug your Terra integration from the terminal.

```sh
brew install tryterra/tap/terra
```

Or tap it first, after which `brew install terra` works:

```sh
brew tap tryterra/tap
brew install terra
```

macOS only. On Linux and Windows, install with npm:

```sh
npm install -g @tryterra/cli
```

## Documentation

[tryterra/terra-cli](https://github.com/tryterra/terra-cli) is the CLI's home:
installation, telemetry, troubleshooting, and the exit code contract.
